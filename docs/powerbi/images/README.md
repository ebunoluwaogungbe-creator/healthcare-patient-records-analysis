# Healthcare Dashboard Screenshots

This folder contains screenshots of the Healthcare Patient Records Analysis dashboard developed using Microsoft Power BI.

## 1. Patient & Clinical Overview

**File:** `healthcare-clinical-overview.png`

This screenshot presents patient-related KPIs, monthly admission trends, age distribution, gender distribution, medical conditions, diagnostic test results, and admission types.

## 2. Operations & Financial Performance

**File:** `healthcare-operations-financial.png`

This screenshot presents billing and insurance metrics, average billing by medical condition, length of stay by admission type, and the hospitals with the highest displayed billing totals.

## Purpose

These screenshots provide a visual preview of the dashboard for readers who want to understand the project without first opening the Power BI report file.
